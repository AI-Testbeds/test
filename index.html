Agentic AI

A course on AI systems that set goals, use tools, and learn from what happens next. We build them, test them, and ask when they should and should not be trusted.

Watch the lectures See the syllabus

About the course

Large language models can now do more than answer questions. They can call tools, write and run code, search for information, and work with other agents to finish multi-step tasks.

This course covers how these systems are designed, how they fail, and how to evaluate them. You will read current research and build working agents in a hands-on project.

  • LevelGraduate / advanced undergraduate
  • PrerequisitesMachine learning basics and Python programming
  • FormatLectures, paper discussions, and a final project

Syllabus

  1. Week 1

    From language models to agents

    What makes a system agentic, and where the idea came from.

  2. Week 2

    Tool use and function calling

    Connecting models to code, search, and external services.

  3. Week 3

    Planning and reasoning

    Breaking goals into steps, and recovering when a step fails.

  4. Week 4

    Memory and retrieval

    Giving agents context that lasts beyond a single conversation.

  5. Week 5

    Multi-agent systems

    Roles, coordination, and when more agents help or hurt.

  6. Week 6

    Evaluation and safety

    Benchmarks, failure analysis, oversight, and guardrails.

  7. Week 7

    Agents in the real world

    Applications in science, health, energy, and transportation.
